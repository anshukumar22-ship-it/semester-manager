SEMESTER MANAGER - PWA WEBSITE

PUBLISH WITH GITHUB PAGES
1. Sign in to https://github.com
2. Create a new repository. Name it semester-manager
3. Choose Public and click Create repository.
4. On the repository page choose Add file > Upload files.
5. Upload ALL FOUR files from this folder: index.html, manifest.json, sw.js, icon.svg
6. Click Commit changes.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose Branch: main and folder: / (root), then Save.
10. Wait a minute or two. GitHub will show your website link in Settings > Pages.

INSTALL ON ANDROID
1. Open the published https://YOUR-USERNAME.github.io/semester-manager/ link in Chrome.
2. Tap the three-dot menu.
3. Choose Install app or Add to Home screen.
4. Confirm. The Semester Manager icon appears on your home screen.

NOTES
- This app stores data in this browser on this device.
- Export JSON backups regularly from the Backup tab.
- The app shell can work offline after the first successful visit.
- Keep your repository public for free GitHub Pages hosting.
